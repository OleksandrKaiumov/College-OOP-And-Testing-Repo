## Мета репозиторію

Цей репозиторій створено для зберігання та оформлення лабораторних робіт з ООП.

Основний вміст:

- вихідні файли з кодом;
- Jupyter Notebook-файли;
- README-звіти до окремих робіт;
- скриншоти результатів виконання;
- файли для роботи із залежностями в окремих лабораторних.

---

## Технології

У репозиторії використовуються:

- **Python**
- **Jupyter Notebook**
- **Markdown**
- **Pipenv / Pipfile** — для частини залежностей
- **Poetry / pyproject.toml** — для окремих лабораторних робіт

> Команди запуску можуть відрізнятися для різних лабораторних робіт. Перед запуском варто переглянути README всередині відповідної папки.
